## 前置准备

### 1. 完成配置（必须）

**⚠️ 重要：** 在部署前，必须完成以下配置：

1. **创建 `config.js`**（从模板复制）：
   ```bash
   cp src/js/config.template.js src/js/config.js
   ```

2. **填写真实配置**（编辑 `src/js/config.js`）：
   ```javascript
   const FEISHU_CONFIG = {
     appId: 'cli_xxxxxxxxxxxx',           // 你的 App ID
     appSecret: 'xxxxxxxxxxxxxxxx',        // 你的 App Secret
     baseToken: 'D2RybBryyaB27QsYp7pcj5xGnfA',   // 你的 base_token
     tableId: 'tblxxxxxxxxxx',            // 你的订单表 table_id
     configTableId: 'tblxxxxxxxxxx',      // 你的配置表 table_id
     apiEndpoint: 'https://open.feishu.cn/open-apis'
   };
   ```

3. **确认 `.gitignore` 包含 `config.js`**（已配置，防止误提交）

### 2. 准备部署文件

**需要部署的文件清单：**

```
sidebar.html                          ✅ 必须
js/app.js                             ✅ 必须
js/api.js                             ✅ 必须
js/calculator.js                      ✅ 必须
js/components/OrderList.js            ✅ 必须
js/components/OrderForm.js            ✅ 必须
js/components/OrderDetail.js          ✅ 必须
js/components/ConfigPanel.js          ✅ 必须
js/utils/formatter.js                 ✅ 必须
js/utils/validator.js                 ✅ 必须
js/config.template.js                  ✅ 可选（供用户参考）
```

**不要部署的文件：**

```
js/config.js                          ❌ 含敏感信息，不要上传
```

### 3. 打包部署文件

```bash
# 在项目根目录执行
mkdir -p dist
cp src/sidebar.html dist/
cp -r src/js dist/

# 删除敏感配置文件
rm dist/js/config.js

# 打包成 ZIP
cd dist
zip -r order-system-sidebar.zip .
```

## 方式一：通过飞书开放平台部署（推荐）

### 步骤 1：进入应用管理

1. 访问 [飞书开放平台](https://open.feishu.cn/)
2. 登录并进入"开发者后台"
3. 找到你的应用（订单管理系统）
4. 点击进入应用详情

### 步骤 2：配置侧边栏

1. 在左侧菜单找到 **"应用侧边栏"** → **"多维表格侧边栏"**
2. 点击 **"创建侧边栏"**

### 步骤 3：上传侧边栏文件

1. **填写侧边栏名称**：`订单管理系统`
2. **上传图标**（可选）：建议尺寸 96x96 px
3. **上传 ZIP 包**：
   - 点击"上传文件"
   - 选择 `order-system-sidebar.zip`
   - 等待上传完成
4. **设置入口文件**：`sidebar.html`
5. 点击 **"保存"**

### 步骤 4：设置权限

1. 在"侧边栏设置"中，找到 **"可见范围"**
2. 选择可见范围：
   - **所有成员**：公司所有人都能看到
   - **指定部门**：只给特定部门使用
   - **指定成员**：只给特定人使用
3. 保存设置

### 步骤 5：发布应用

1. 回到应用详情页
2. 点击 **"版本管理与发布"**
3. 点击 **"创建版本"**
4. 填写版本信息：
   - **版本号**：1.0.0
   - **更新说明**：初始版本，支持订单管理、利润自动计算
5. 点击 **"提交审核"**
6. 等待飞书审核（通常 1-2 个工作日）
7. 审核通过后，点击 **"发布"**

## 方式二：通过多维表格直接上传

如果不想通过开放平台审核，可以直接在多维表格中上传（仅当前表格可用）。

### 步骤 1：打开多维表格

1. 打开你的订单管理多维表格
2. 点击右上角 **"..."（更多）**
3. 选择 **"侧边栏"** → **"添加侧边栏"**

### 步骤 2：上传文件

1. 点击 **"上传 HTML 文件"**
2. 选择 `src/sidebar.html`
3. 系统会自动解析 HTML 中的 CDN 依赖（Tailwind CSS、Axios、Tabulator）
4. 填写侧边栏名称：`订单管理系统`
5. 点击 **"确定"**

### 步骤 3：测试侧边栏

1. 在多维表格右侧会出现侧边栏面板
2. 点击"订单管理系统"
3. 检查应用是否正常加载
4. 测试订单创建、编辑、删除功能

**⚠️ 注意：** 此方式上传的侧边栏只能在当前多维表格中使用，不能在其他表格中复用。

## 配置侧边栏权限

### 1. 应用级权限

在飞书开放平台配置：

1. 进入应用详情
2. 点击 **"权限管理"**
3. 确保已开启以下权限：
   - `bitable:app:readonly`
   - `bitable:app:readwrite`
   - `drive:drive:readonly`
4. 如果权限需要审核，提交审核申请

### 2. 多维表格权限

确保应用有访问多维表格的权限：

1. 打开多维表格
2. 点击右上角 **"分享"**
3. 添加应用为"可编辑"成员：
   - 搜索你的应用名称
   - 选择权限级别："可编辑"
   - 点击"确定"

## 验证部署

部署完成后，进行以下验证：

### 1. 基本功能验证

- [ ] 打开多维表格
- [ ] 点击右侧"侧边栏"图标
- [ ] 选择"订单管理系统"
- [ ] 应用正常加载，显示订单列表
- [ ] 点击"新建订单"，表单正常显示
- [ ] 填写订单信息，利润自动计算
- [ ] 保存订单，数据写入多维表格
- [ ] 编辑订单，数据更新成功
- [ ] 删除订单，数据删除成功

### 2. 计算准确性验证

创建测试订单，验证利润计算：

**测试用例 1：**
- 单价：100 元
- 成本：60 元
- 佣金：5 元
- 重量：1 kg
- 运输方式：陆运
- 单价（卢布）：890 卢布

**预期结果：**
- 税 = 100 × 3% = 3 元
- 尾程 = MAX(MIN(890 × 2%, 200), 15) ÷ 11.89 = MAX(17.8, 15) ÷ 11.89 ≈ 1.50 元
- 运费 = 根据规则计算（假设 93 元）
- 利润 = 100 - 60 - 5 - 93 - 3 - 1.50 = -62.50 元

**⚠️ 注意：** 如果利润为负，说明运费过高，需要调整销售策略。

### 3. 配置功能验证

- [ ] 点击右上角"设置"图标
- [ ] 修改卢布汇率（例如：从 89.12 改为 90.00）
- [ ] 点击"保存"
- [ ] 刷新页面，确认汇率已更新
- [ ] 新建订单，验证计算是否使用新汇率

## 常见问题

### Q1：侧边栏无法加载，显示"加载失败"

**可能原因：**
1. `config.js` 配置错误
2. 飞书应用未启用
3. 权限未开启

**解决方法：**
1. 检查浏览器控制台（F12），查看错误信息
2. 确认 `config.js` 中的 App ID 和 App Secret 是否正确
3. 确认飞书应用已启用（开放平台 → 应用详情 → 应用状态：已启用）
4. 确认权限已开启（开放平台 → 权限管理）

### Q2：API 调用失败（401 Unauthorized）

**可能原因：**
- App ID 或 App Secret 错误
- App Secret 已过期

**解决方法：**
1. 重新获取 App Secret（开放平台 → 凭证与基础信息 → 重置 Secret）
2. 更新 `config.js` 中的配置
3. 重新部署

### Q3：无法读取多维表格数据（404 Not Found）

**可能原因：**
- `baseToken` 错误
- `tableId` 错误
- 应用无权限访问该多维表格

**解决方法：**
1. 检查 `baseToken` 是否正确（从 URL 获取）
2. 检查 `tableId` 是否正确（从 URL 获取）
3. 将应用添加为多维表格的"可编辑"成员

### Q4：利润计算不准确

**可能原因：**
- 汇率配置错误
- 运费规则配置错误

**解决方法：**
1. 检查配置面板中的汇率是否正确
2. 运行单元测试验证计算器：
   ```bash
   cd test
   node calculator.test.js
   ```
3. 检查 `src/js/calculator.js` 中的 `shippingRules` 是否正确

### Q5：侧边栏在某些设备上显示异常

**可能原因：**
- CSS 兼容性问题
- 屏幕分辨率过低

**解决方法：**
1. 确保使用现代浏览器（Chrome 60+、Firefox 55+、Safari 12+）
2. 检查 `sidebar.html` 中 Tailwind CSS 的 CDN 是否正常加载
3. 调整侧边栏宽度（飞书侧边栏支持拖拽调整宽度）

## 安全注意事项

### 1. 保护敏感信息

**⚠️ 永远不要将以下信息提交到 Git：**

- `config.js`（含 App ID、App Secret、baseToken 等）
- `.env` 文件（如果使用环境变量）
- 任何包含敏感信息的日志文件

**已配置的防护措施：**
- `.gitignore` 已包含 `config.js`
- `config.template.js` 仅供参考，不含真实凭证

### 2. 最小化权限

只开启应用所需的权限，避免过度授权：

**必需权限：**
- `bitable:app:readonly`
- `bitable:app:readwrite`

**可选权限：**
- `drive:drive:readonly`（如果需要访问云文档）

**不要开启的权限：**
- `contact:contact`（通讯录权限，不需要）
- `im:message`（消息权限，不需要）
- `calendar:calendar`（日历权限，不需要）

### 3. 定期更新 Secret

建议每 3-6 个月重置一次 App Secret：

1. 开放平台 → 凭证与基础信息 → 重置 Secret
2. 更新 `config.js` 中的 `appSecret`
3. 重新部署应用

## 后续维护

### 1. 更新应用

当应用需要更新时：

1. 修改源代码
2. 本地测试通过
3. 重新打包 `order-system-sidebar.zip`
4. 在开放平台重新上传侧边栏文件
5. 保存并发布新版本

### 2. 监控错误

定期查看浏览器控制台，检查是否有 API 调用失败或 JS 错误。

**常见错误：**
- `401 Unauthorized`：凭证错误
- `404 Not Found`：tableId 错误
- `429 Too Many Requests`：API 限流

### 3. 优化性能

如果加载速度慢，可以考虑：

- 减少单次加载的订单数量（分页加载）
- 使用批量 API（已集成）
- 优化 Tabulator 渲染性能（虚拟滚动）
